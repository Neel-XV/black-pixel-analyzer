# Black Pixel Analyzer

> Analyze and optimize images for AMOLED screens — runs **entirely in the browser** via WebAssembly.

## Overview

Black Pixel Analyzer calculates the black-pixel percentage of an image and lets you "blackify" near-black pixels (below a configurable threshold) to pure black.  
This maximizes OLED/AMOLED power savings and reduces burn-in risk.

The `wasm-web` branch re-implements the original Python/Tkinter tool as a **Rust → WebAssembly** pixel engine bundled with a **React + Vite** frontend — deployable as a static site on [Render](https://render.com).

## Architecture

```
black-pixel-analyzer/
├── crates/
│   └── pixel-engine/        ← Rust library compiled to WASM
│       ├── Cargo.toml
│       └── src/lib.rs       ← analyze(), blackify(), blackify_and_analyze()
├── web/                     ← Vite + React frontend
│   ├── src/
│   │   ├── App.jsx          ← main UI (drag-drop, tabs, slider, download)
│   │   ├── hooks/
│   │   │   ├── useWasm.js   ← lazy WASM loader (singleton)
│   │   │   └── useImageLoader.js  ← canvas-based decode/encode
│   │   └── wasm/            ← generated by wasm-pack (git-ignored)
│   ├── vite.config.js
│   └── package.json
├── Cargo.toml               ← workspace root
├── render.yaml              ← Render static site config
└── black_pixel_converter.py ← original Python/Tkinter app (main branch)
```

### Why Rust + WASM?

| | Python/Tkinter | Rust/WASM |
|---|---|---|
| **Runs in browser** | ✗ | ✅ |
| **Deployable on Render** | ✗ (server needed) | ✅ (static site, free tier) |
| **Pixel loop speed** | NumPy (C extension) | Rust → WASM ≈ native speed |
| **Memory model** | GC + numpy heap | Zero-copy `&[u8]` slices |
| **Bundle size** | N/A | ~50 KB .wasm (release + lto + opt-s) |

## Local development

### Prerequisites

| Tool | Install |
|------|---------|
| **Rust** (stable) | `rustup` — https://rustup.rs |
| **wasm-pack** | `cargo install wasm-pack` or https://rustwasm.github.io/wasm-pack |
| **Node 18+** | https://nodejs.org |

### 1 — Build the WASM module

```bash
# From repo root:
wasm-pack build crates/pixel-engine --target web --out-dir ../../web/src/wasm --release
```

Or use the npm script:

```bash
cd web
npm run wasm:build
```

### 2 — Install JS dependencies

```bash
cd web
npm install
```

### 3 — Start the dev server

```bash
cd web
npm run dev
# → http://localhost:5173
```

### 4 — Production build

```bash
cd web
npm run build      # runs wasm:build then vite build
npm run preview    # serve web/dist locally
```

## Deploy to Render

1. Push the `wasm-web` branch to GitHub.
2. Create a new **Static Site** on [render.com](https://render.com) and point it at this repo.
3. Render auto-detects `render.yaml` — no manual config needed.
4. Every push to `wasm-web` triggers a rebuild.  
   Pull-request previews are enabled by default.

> **Note:** The Render build script installs Rust and wasm-pack at build time.  
> Build time is ~3–5 min on first run; subsequent builds are faster due to Render's layer caching.
